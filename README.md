# GastroFlow (ALFA)
**System Zarządzania Lokalem**

Aplikacja stworzona dla lokalnych jak i większych firm gastronomicznych zmagających się z "overbookingiem" stolików, problemami z zamówieniami, itp

## Stos technologiczny
* **Baza danych:** Oracle (SQL + zaawansowany PL/SQL)
* **Backend:** Python (FastAPI)
* **Frontend:** HTML/CSS + React.
* **Inne:** Docker.
